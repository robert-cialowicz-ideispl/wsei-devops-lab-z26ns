## Polecenia Linux

| Polecenie  | Do czego służy                            | Moja obserwacja lub wynik                                         |
| ---------- | ----------------------------------------- | ----------------------------------------------------------------- |
| `pwd`      | Pokazuje bieżący katalog.                 | Zwróciło katalog w którym znajduję się                            |
| `ls -la`   | Wyświetla pliki, w tym ukryte.            | . .. .git .gitignore README.md lab1 lab2 lab3                     |
| `mkdir -p` | Tworzy katalogi.                          | Utworzyło folder lab2/submissions                                 |
| `grep -n`  | Wyszukuje tekst i pokazuje numer wiersza. | 2: Druga linia                                                    |
| `wc -l`    | Liczy wiersze pliku.                      | 2 /var/folders/3r/0fhm1d2j71q3z1f9h0ytxq0w0000gn/T/tmp.8zTKuxBHc3 |
